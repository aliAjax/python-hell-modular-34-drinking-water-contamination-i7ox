市政饮用水污染响应

使用 JSON API 创建污染事件、登记水源或管网记录，并完成复检、通知、冲洗、消毒和恢复。

GET /health
GET /api/state
POST /api/items
POST /api/items/{id}/sources
POST /api/items/{id}/actions
POST /api/occupancies
POST /api/valve-receipts
GET /api/occupancies/{order_no}
GET /api/branches/{branch_id}/ledger

升级后的事件冲洗需提供 branch_id；所有隔离阀门确认关断后才能冲洗。旧事件继续沿用无隔离凭证流程。
